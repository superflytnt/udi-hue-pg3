# PG3x Philips Hue configuration

See [README.md](README.md#configuration) for current pairing, bridge configuration and optional heartbeat settings.

This version uses Hue API v2, PG3 custom data for saved bridge credentials and the `bridges`, `debug`, `ignore_second_on` and `heartbeat_url` custom parameters. Old PG2 `ip`/`username` and `~/.python_hue` instructions do not apply.
